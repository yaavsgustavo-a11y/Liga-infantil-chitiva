# Liga Infantil Escolar Andrés Chitiva

Repositorio del **proyecto estratégico, comercial, de marketing, diseño, producción audiovisual, experiencia de marca, captación de alumnos y coordinación interdepartamental** de la Liga Infantil Escolar organizada por la **Academia de Fútbol / Complejo Deportivo Andrés Chitiva** (Pachuca / Mineral de la Reforma, Hidalgo).

> **Estado general:** Borrador para validación interna · Versión 1.0 · Última actualización: **04/09/2026** · Responsable del repositorio: **Coordinación de Marketing y Comercial**.

---

## 1. Qué es el proyecto

La Liga Infantil Escolar es una competencia de fútbol para alumnos de primaria que representan a su colegio. Se diseña **desde el origen como un canal de adquisición de nuevos alumnos para la Academia**, no únicamente como un torneo deportivo.

La liga funciona simultáneamente como: producto comercial para colegios, plataforma de posicionamiento, fuente de contenido, herramienta de relación con familias, vitrina del Complejo Deportivo, base para futuras temporadas y activo de marca escalable.

## 2. Objetivos (en orden de prioridad)

1. **Rentabilidad.**
2. Captación de nuevos alumnos para la Academia.
3. Captación y relación con nuevos colegios.
4. Posicionamiento de la Academia y del Complejo Deportivo.
5. Generación de una plataforma deportiva escolar permanente.
6. Creación de contenido y activos reutilizables.
7. Desarrollo de una marca de liga con potencial de crecimiento.

**Regla fundamental del proyecto:** todo debe estar diseñado alrededor del embudo
`COLEGIOS → EQUIPOS → PARTICIPANTES → EXPERIENCIA → PROSPECTOS → ALUMNOS DE ACADEMIA → RETENCIÓN → RENTABILIDAD`.

## 3. Alcance de este encargo

Este proyecto desarrolla **a detalle completo** las áreas de Marketing, Comercial, Diseño, Producción Audiovisual, Experiencia de Marca, Comunicación, Captación de Alumnos y Coordinación Interdepartamental.

Las definiciones **técnicas deportivas, financieras detalladas, operativas, tecnológicas y de reglamento/legal** NO se desarrollan aquí: se documentan como dependencias y se solicitan formalmente a sus responsables (ver `17_solicitudes_departamentos/`).

## 4. Áreas involucradas y responsabilidades

| Área | Rol en el proyecto |
|---|---|
| Dirección / Finanzas | Aprueba propuesta, presupuesto, precios y condiciones comerciales. |
| Administración / Operación | Valida capacidad, horarios, logística, seguridad y jornadas. |
| Marketing | Estrategia, comunicación, campañas, captación, KPIs. |
| Comercial | Prospección y cierre de colegios; seguimiento; renovación. |
| Diseño | Identidad y todas las piezas gráficas. |
| Producción Audiovisual | Cobertura, video, fotografía y banco de contenidos. |
| Academia | Recepción y conversión de prospectos; clases muestra. |
| Responsable del modelo deportivo | Categorías, formato, reglas, calendario deportivo. |
| Responsable del reglamento / Legal | Reglas, protección de menores, datos, uso de imagen. |
| Tecnología | Plataforma, resultados, grabación y publicación. |
